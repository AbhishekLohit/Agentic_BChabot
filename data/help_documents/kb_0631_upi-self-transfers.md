# UPI - Self Transfers

Yes, you can use UPI to send money from one bank account to another if both accounts are linked to different UPI IDs. If both accounts are linked to the same UPI app, you can simply select the source and destination accounts within the app. If the accounts are in different apps, you can send money using the UPI ID of the other account.

If both accounts are in the same UPI app, select 'Transfer between accounts'. If not, enter the UPI ID of your other account and send the money.

The user learns that UPI can be used for self-transfers between accounts.
