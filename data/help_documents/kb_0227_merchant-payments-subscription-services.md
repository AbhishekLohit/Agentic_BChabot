# Merchant Payments - Subscription Services

For a subscription box service with varying amounts, UPI AutoPay (e-mandate) may not be suitable because the amount can change each month. In such cases, you can use the 'Collect Request' feature to send a request each month for the exact amount. Alternatively, you can use a payment gateway that allows dynamic amounts in mandates (some gateways like Razorpay support this). Another option is to create a payment link each month and send it to the customer. The customer can then pay the exact amount. For a seamless experience, consider using a subscription management platform that integrates with UPI payment gateways.

If you have a fixed amount each month, use UPI AutoPay. For varying amounts, use the 'Collect Request' or send a payment link each month. You can automate this using a payment gateway's APIs to generate links automatically. Communicate clearly with your customers about the payment schedule and the amount due each month. Keep a record of all payments to manage the subscription lifecycle.

The merchant learns how to handle variable recurring payments with UPI.
