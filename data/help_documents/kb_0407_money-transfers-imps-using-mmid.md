# Money Transfers - IMPS using MMID

Yes, if you have the recipient's mobile number and MMID, you do not need the IFSC code for an IMPS transfer . The MMID is a 7-digit number unique to the recipient and their bank account. You can initiate the transfer using their mobile number and MMID instead of the account number and IFSC.

Ask the recipient for their MMID (Mobile Money Identifier). Log in to your mobile banking app. Choose IMPS and select 'Mobile Number and MMID' as the beneficiary type. Enter the recipient's mobile number and MMID. Enter the amount and confirm. The transfer will be instant.

The user learns that IMPS transfers can be done using mobile number and MMID without the IFSC code.
