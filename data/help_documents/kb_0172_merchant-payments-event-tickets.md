# Merchant Payments - Event Tickets

For event ticket sales, the best way to accept UPI payments is to use a ticketing platform or a payment gateway that supports event booking. Platforms like BookMyShow, Townscript, or Paytm Insider have built-in UPI options. If you are selling tickets directly, you can use a payment gateway like Razorpay or PayU to create a checkout page with UPI as a payment option. You can also generate unique payment links for each ticket or attendee. Ensure the payment confirmation automatically triggers the ticket delivery (e.g., via email or SMS).

Choose a ticketing platform that supports UPI, or integrate a payment gateway with your own website. For each event, create a payment page with a UPI option. You can also generate a dynamic QR code for each ticket. Ensure the ticket delivery is automated upon payment confirmation. For large events, consider using a waitlist system in case of high demand. Also, have a refund policy in case of cancellations.
