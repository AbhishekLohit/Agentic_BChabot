# UPI - UPI ID Creation

A UPI ID is a unique identifier (like yourname@bank) that you can use to send and receive money via UPI. You can create a UPI ID when you set up UPI on your banking app or UPI app. Usually, you can choose your own UPI ID or accept the default one provided by the app. You can also create multiple UPI IDs linked to the same bank account.

Download a UPI app, register with your bank account, and create a UPI ID. You can customize it or use the default one.

The user learns how to create a UPI ID.
