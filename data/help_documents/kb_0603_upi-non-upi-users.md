# UPI - Non-UPI Users

No, UPI requires both the sender and the recipient to have a UPI ID. If the recipient is not a UPI user, you cannot send money via UPI. You will need to use NEFT, RTGS, IMPS, or other payment methods that only require the beneficiary's account number and IFSC code.

Ask the recipient to set up UPI on their mobile banking app. If they cannot, use NEFT, RTGS, or IMPS to transfer the money using their account number and IFSC.

The user learns that UPI requires both parties to have UPI IDs.
